## Descripción general del sistema

Este programa con interfaz de usuario desarrollado en java consiste en representar la gestión de pedidos, repartidores y entregas aplicando operaciones CRUD conectadas a una base de datos remota.

---

## Estructura general del proyecto

```plaintext
📁 src/main/java
├── app/         # Clase principal
├── controller/  # Clase Gestor
├── dao/         # Interfaces DAO
  ├── impl/      # Clases implementadas DAO
├── model/       # Entidades e interfaces
├── util/        # Clase conectora de BD
├── view/        # Vistas de usuario
script_poo.sql   # Script de BD
````

## Instrucciones para ejecutar el proyecto

1. Clona el repositorio desde GitHub:

```bash
git clone https://github.com/strakelov/desarrollo-orientado-objetos-2
```

2. Abre el proyecto en IntelliJ IDEA.

3. Ejecuta el archivo `Main.java` ubicado en `src/main/java/app/Main.java`.
